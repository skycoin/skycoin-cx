# code CLASS STATUS file function [note]
#
# CLASS is where the strings run. I every instruction, O every run of that
# opcode, P printing a value, E a failure branch only, B a boundary that hands
# the string to Go, the OS or compiler code run by an opcode (I/O, system

# path) or cxfx (open in t6-cxfx, which only the build with the cxfx tag has,
# checked by ./check-strhot.sh -tags cxfx, #432).
